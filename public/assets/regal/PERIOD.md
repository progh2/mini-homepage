# 왕실(regal) 스킨 시대 고증 메모

**기준 시대: 빅토리아 후기, 1880~1890년대 영국.** 3차 작업에서 실내도 이 시대로 다시 꾸몄습니다.
조지 시대(애덤 양식) 기둥 장식과 금색 판 몰딩은 줄이고, 모리스 벽지, 링크러스타·아나글립타 돋을무늬 굽도리, 참나무 판벽, 고딕 아치 문, 가스등과 전기등, 흑단 탐미주의 가구를 넣었습니다.
18세기 그림과 오래된 소장품은 "1890년대 집에 이미 있던 물건"으로 남깁니다. **인물의 옷차림과 손에 드는 물건은 1880~1890년대**를 따릅니다.

- 출처를 확인한 내용은 오른쪽에 출처 번호를 붙였습니다.
- 출처를 찾지 못하고 그럴듯하게 짐작한 내용은 **추정**이라고 적었습니다.

**이 집의 결정**: 대부분의 방은 **가솔리어(가스 샹들리에)와 가스 벽등**(유백 유리 갓)을 씁니다. 가스의 눈부심을 줄이려 갓을 씌웠다는 기록이 있습니다 [10].
**서재만 일렉트롤리어(전구가 아래를 향한 전기 샹들리에)**로 했습니다. 크래그사이드처럼 1880년대에 일찍 전기를 들인 집이라는 설정입니다 [7], [8]. 서재 책상의 꽃병 램프(칠보) 모양은 **추정**입니다.
3D에서는 성능 규칙대로 방마다 실시간 빛은 하나와 환경광뿐이고, 나머지 등은 빛나는 재질로만 표현합니다.
