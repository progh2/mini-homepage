# 나만의 링크트리 양식 (미니홈피 만들기 키트)

이 파일은 나만의 미니홈피(링크트리)를 만들기 위한 **빈칸 채우기 양식**입니다.
아래 순서대로 진행하세요.

1. 이 저장소(템플릿)를 GitHub에서 복사(포크)하세요. 저장소 이름은 "meyo-lab"이 아니라 나만의 이름(예: `mini-homepage`)으로 새로 지어주세요. AI 코딩 도구에 맡기면 이 과정도 대신 해줍니다.
2. 아래 빈칸을 천천히, 아는 만큼만 채우세요. 모르는 항목은 비워둬도 됩니다.
3. 다 채웠으면 **이 파일 전체를 복사**해서 Claude Code 같은 AI 코딩 도구에 붙여넣고 이렇게 말하세요.

   > 이 양식대로 내 링크트리를 만들어줘. `src/config/linktree.ts`와 `src/config/theme.ts`를 수정해줘.

4. AI가 수정을 마치면 `npm run build`가 잘 되는지 확인해달라고 하고, 마지막으로 배포까지 부탁해서 완성된 내 미니홈피 주소를 받으세요.

**주의할 점**

- 전화번호, 집주소 같은 개인정보는 적지 마세요.
- 남에게 공개하면 안 되는 비공개 링크는 적지 마세요.
- 사진을 쓰고 싶다면, 그 사진 파일을 미리 `public/assets/` 폴더 안에 넣어두고 파일 이름을 아래에 적어주세요. AI는 사진을 직접 만들 수 없습니다.
- 이 저장소를 열면 원래 만든 사람(미요Lab)의 사진·소개글·게시판 예시가 이미 채워져 있습니다. 그대로 두지 말고, 이 양식에 적은 내 것으로 전부 바꿔야 합니다.

- [ ] Firebase(Firestore) 프로젝트를 만들겠습니다.

체크했다면, Firebase 콘솔에서 프로젝트를 만든 뒤 웹 앱 설정값을 `.env.local`의 `NEXT_PUBLIC_FIREBASE_*` 항목에 채우고, `firestore.rules` 파일을 그 프로젝트에 배포해달라고 AI에게 요청하세요. AI는 Firebase 프로젝트를 대신 만들거나 키를 발급할 수 없습니다.
